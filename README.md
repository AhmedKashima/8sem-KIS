### 📚 Основные темы

| Тема | Описание |
|:---|:---|
| 🖥️ **Знакомство с R** | История, назначение, консольный режим |
| 📦 **Пакеты** | Установка, загрузка, справка |

### 💻 Примеры кода

```r
# Работа с векторами
x <- c(1, 2, 3, 4, 5)
x[x > 3]              # [1] 4 5

# Статистические функции
mean(x)               # 3
sd(x)                 # 1.581139

# Условное выполнение
if (mean(x) > 3) {
  print("Среднее больше 3")
} else {
  print("Среднее меньше или равно 3")
}
```
